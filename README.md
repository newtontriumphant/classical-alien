# classical-alien
The Classical Alien is a simple platformer game designed for Jumpstart Haven, designed in Godot, featuring Orff's Carmina Burana :)

The premise behind this game is that the alien is supposed to embody Gizzy, who obviously doesn't sh*wer, and to blast classical music in your ears at +10dB because of course that's what an alien would do!

Controls are straightforward, it is a platformer after all. To win, get both the flag and the key :)
